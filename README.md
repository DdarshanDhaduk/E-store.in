🛒 E-Store.in – Java Spring Boot E-commerce & Movie Streaming Platform
🔧 Technologies Used
Java, Spring Boot, Spring Security, MySQL, Thymeleaf 

HTML, CSS, JavaScript

Gmail SMTP, REST APIs

📌 Features
🔐 Role-Based Access Control

Admin: Add/Update/Delete products, view all orders, approve resend requests

User: Browse products, stream movies, place orders, receive bill via email

Delivery Boy: Track assigned orders

🎬 Movie Streaming Integration

Users can enjoy streaming while shopping

📦 Order & Resend System

Users receive email bill instantly

Resend request system for damaged/undelivered products

📈 Real-time Order Tracking

Users and delivery boys can track order status

📱 Responsive UI

Clean design with HTML/CSS/JS

Mobile and desktop friendly

🛠️ Database Design

MySQL database for users, products, orders, movie, whislist...
